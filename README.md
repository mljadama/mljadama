# Hi there, I'm mljadama 👋

I'm a software developer passionate about building impactful digital health tools and cross-platform mobile apps. I enjoy turning complex problems into clean, user-friendly solutions — from clinical decision-support systems running on DHIS2 to mood-driven soundboard experiences on mobile.

- 🔭 Currently working on **[Maternal Health Risk Alert](https://github.com/mljadama/maternal-health-risk-alert)** — a DHIS2 web app for automated high-risk pregnancy detection in antenatal care, now live on the DHIS2 App Hub ✅
- 📱 Built **[Mood Sounds](https://github.com/mljadama/mood-sounds)** — a cross-platform mood soundboard app powered by Supabase and React Native/Expo
- 🌱 Always learning more about digital health standards, cloud backends, and performance optimization
- 💬 Ask me about React, React Native, DHIS2 app development, or Supabase
